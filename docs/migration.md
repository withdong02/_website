# 纸艺个人网站迁移计划

更新：2026-11-21。用户确认前两个页面（首页场景与博客页）按当前范围基本完成，本轮收口。首页已有四季游览、春季介绍与夏季四入口；博客保留 21 篇文章及历史路径，栏目、正文、分页、文章目录和场景往返已接通，阅读时间已移除。站点已上线，`main` 自动检查、构建与发布已验证。返回优先恢复原场景文档，未命中浏览器缓存时简短等待后恢复位置。

搜索、评论、春季音乐、冬季留言与联系、真机及低性能设备验收继续保留为后续事项。独立相册与秋季照片墙已通过 COS JPG 接入 8 张用户照片，CI 使用远程清单、无需原件，尚未发布；具体推进见“当前下一步”，旧日期验收记录保留为历史。

## 方向

- 新项目统一在 `D:\_website` 建设，原博客 `D:\Blog` 作为迁移来源保留。
- 使用用户自己的服务器托管静态构建产物，不依赖 Vercel/Cloudflare；2026-11-19 已按专项授权完成生产替换。
- 基于 Aimee 的四季纸艺世界，沿用 React、React Three Fiber、Three.js、GSAP、Lenis 与既有闭环路线；不因场景换素材重选框架。
- 春季首屏已调整；保持原探索距离和滚动节奏，不缩短春到夏的路程。首版不增加自由行走、物理任务、收集或解锁系统。
- 博客和相册是独立 HTML 页面，通过场景入口跳转；完整阅读、分类与相册浏览不塞进三维画面或场景内阅读弹层。
- 保留 Hugo 内容渲染能力；全量文章迁移、场景往返与统一静态构建已完成阶段四验证，不重写现有渲染链路。
- 四季素材、主色及入口造型已获整体认可；首页与博客按当前范围基本完成。后续沿用现有构图接入相册及真实媒体，设备验收单独跟踪。
- 原有文章 URL、图片、正文排版、代码、锚点和评论关联是迁移对象；旧首页整套动画与全部样式不原样叠加进新站。

## 已确定的产品方向

| 区域 | 功能 | 设计约束 |
| --- | --- | --- |
| 春季 | 自我介绍、音乐，首次进入的落点 | 简短介绍与主动播放；保留原探索节奏，不要求读完或播放后才能前进 |
| 夏季 | 博客入口，网站核心功能 | 点击进入独立博客页面；完整提供文章列表、标签、分类、归档、搜索与正文目录等原有能力 |
| 秋季 | 沿途相册入口 | 点击进入独立相册页面；场景以金黄色为方向，重新编排原夏季的相机、照片、路线等素材 |
| 冬季 | 雪夜来信：留言与联系 | 暖屋与 `contact me` 邮筒素材已确认；独立页面后续接入 |

- 每个区域的地面与背板使用一致主色，四季之间仍有色彩区别；纸纹、接触阴影、局部景物可以形成层次。
- 安静、沉浸、纸艺气质是整体方向；保留可发现的内容入口，不要求访客完成游戏任务。
- 最新角色方向：四季 4 套服装、6 个主要角色视角/动作的小男孩已实装，保留表情切换；回声已作为春季湖蓝色纸艺摆件接入，旧素材保留。
- 当前独立博客使用同标签页原生导航，保留真实 URL、直接访问、刷新和浏览器的默认打开方式；相册接入沿用同样原则。
- 首次进入落在春季；从博客或相册返回则恢复离开时的位置。冷启动与返回恢复必须分开处理。
